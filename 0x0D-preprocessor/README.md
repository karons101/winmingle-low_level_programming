# 0x0D. C - Preprocessor

This project covers the basics of the C Preprocessor, including macros (object-like and function-like) and predefined macros.

## Learning Objectives
* What macros are and how they work
* Difference between object-like and function-like macros
* Common predefined macros (__FILE__, __LINE__, etc.)
* Protecting header files with include guards

## Files
* 0-object_like_macro.h: Defines SIZE as 1024
* 1-pi.h: Defines PI as 3.14159265359
* 2-main.c: Prints the name of the file
* 3-function_like_macro.h: Macro ABS(x)
* 4-sum.h: Macro SUM(x, y)
