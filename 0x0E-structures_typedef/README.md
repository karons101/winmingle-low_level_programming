# 0x0E. C - Structures, typedef

This project covers the implementation of structures and typedef in C.

## Files
* dog.h: Header file containing struct dog and dog_t definition.
* 1-init_dog.c: Function to initialize a struct dog.
* 2-print_dog.c: Function to print a struct dog.
* 4-new_dog.c: Function that creates a new dog (with deep copies of strings).
* 5-free_dog.c: Function that frees a dog_t.
