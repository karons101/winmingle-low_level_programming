# 0x0A. C - argc, argv

## Description
This project covers the use of command-line arguments in C. It explores how to handle `argc` (argument count) and `argv` (argument vector) within the `main` function.

## Tasks
* **0-whatsmyname.c**: Prints the program's name.
* **1-args.c**: Prints the number of arguments passed into it.
* **2-args.c**: Prints all arguments received.
* **3-mul.c**: Multiplies two numbers.
* **4-add.c**: Adds positive numbers with digit validation.
* **100-change.c**: Minimum coins needed for change (Greedy Algorithm).

## Requirements
* Compiled on Ubuntu 20.04 LTS
* Flags: -Wall -Werror -Wextra -pedantic -std=gnu89
