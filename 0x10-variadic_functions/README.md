# 0x10. C - Variadic Functions

## Summary
This project covers variadic functions in C, which are functions that accept a variable number of arguments.

## Concepts
* `va_list`: Type to hold the information needed by the macros.
* `va_start`: Enables access to variadic function arguments.
* `va_arg`: Accesses the next variadic function argument.
* `va_end`: Ends traversal of variadic function arguments.

## Files
* 0-sum_them_all.c: Sums all parameters.
* 1-print_numbers.c: Prints numbers with a separator.
* 2-print_strings.c: Prints strings with a separator.
* 3-print_all.c: A flexible print function for multiple types.
