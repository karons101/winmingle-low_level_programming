# 0x14. C - Bit manipulation

## Description
This project covers bitwise operators in C. It focuses on manipulating individual bits within variables using AND (`&`), OR (`|`), XOR (`^`), NOT (`~`), and bit shifts (`<<`, `>>`).

## Files
All the following files are written in C:

| Filename | Description |
| -------- | ----------- |
| `0-binary_to_uint.c` | Converts a binary string to an `unsigned int`. |
| `1-print_binary.c` | Prints the binary representation of a number. |
| `2-get_bit.c` | Returns the value of a bit at a given index. |
| `3-set_bit.c` | Sets the value of a bit to 1 at a given index. |
| `4-clear_bit.c` | Sets the value of a bit to 0 at a given index. |
| `5-flip_bits.c` | Returns the number of bits needed to flip to get from one number to another. |
| `100-get_endianness.c` | Checks the endianness of the system. |
