# 0x15. C - File I/O

## Description
This project focuses on the basics of file handling in C using system calls. It covers opening, reading, writing, and closing files, as well as managing file descriptors and permissions.

## Tasks
* **0. read_textfile**: Reads a text file and prints it to the POSIX standard output.
* **1. create_file**: Creates a file with specific permissions (`rw-------`).
* **2. append_text_to_file**: Appends text at the end of a file.
* **3. cp**: Copies the content of a file to another file.

## Requirements
* Editors: `vi`, `vim`, `emacs`
* OS: Ubuntu 20.04 LTS
* Compiler: `gcc` (-Wall -Werror -Wextra -pedantic -std=gnu89)
* Only `malloc`, `free`, and `exit` allowed.
* System calls: `open`, `close`, `read`, `write`.
